3. source .venv/bin/activate
4. python -m streamlit run /home/manics28b/wanderbot/app.py --browser.serverAddress=localhost --server.enableCORS=false --server.enableXsrfProtection=false --server.port=8090
5. Open Web Preview and select port 8090.
